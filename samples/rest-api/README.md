# rqb REST API Sample

Compile-checked REST service shape for the sqlx-first API.

It shows:

- HTTP DTOs kept separate from database row structs.
- Shared `rqb-sample-schema` generated by `rqb-cli` from `../schema.sql`.
- Services that run the same rqb statements against a `PgPool` or a transaction
  connection.
- JSON `SearchRequest` applied on top of server-owned filters, with local
  REST pagination built from `limit`, `offset`, and `Select::count()`.
- `Insertable` DTOs for write mappings.
- Closure-style `tx!` transactions.

The sample uses `PgPoolOptions::connect_lazy`, so `cargo check` does not need a
running database.

Regenerate the shared sample schema crate from the sample SQL:

```bash
make generate-sample-schema
```

Run the compile-checked router bootstrap with:

```bash
cargo run --manifest-path samples/rest-api/Cargo.toml
```
