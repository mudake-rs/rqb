# rqb REST API Sample

Compile-checked REST service shape for the sqlx-first API.

It shows:

- HTTP DTOs kept separate from database row structs.
- Checked-in `src/schema.rs` generated by `rqb-cli` from `../schema.sql`.
- Services that run the same rqb statements against a `PgPool` or a transaction
  connection.
- JSON `SearchRequest` applied on top of server-owned filters.
- `Insertable` DTOs for write mappings.
- Closure-style `tx!` transactions.

The sample uses `PgPoolOptions::connect_lazy`, so `cargo check` does not need a
running database.

Regenerate all sample schema modules from the shared sample SQL:

```bash
make generate-sample-schema
```
