# rqb REST API Sample

Compile-checked REST service shape for the sqlx-first API.

It shows:

- HTTP DTOs kept separate from database row structs.
- Checked-in `src/schema.rs` generated by `rqb-cli` from the database schema.
- Services that run the same rqb statements against a `PgPool` or a transaction
  connection.
- JSON `SearchRequest` applied on top of server-owned filters.
- Explicit `begin` / `commit` and closure-style `rqb::tx!`.

The sample uses `PgPoolOptions::connect_lazy`, so `cargo check` does not need a
running database.

Regenerate the schema module after applying `schema.sql` to a local Postgres
database:

```bash
cargo run -p rqb-cli -- generate \
  --database-url "$DATABASE_URL" \
  --schema public \
  --table app_users \
  --table orders \
  --out samples/rest-api/src/schema.rs
```
